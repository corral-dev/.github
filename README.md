# Corral

[Install Corral](https://github.com/corral-dev/corral#install) to run coding agents in one terminal, or choose a [native Apple client](https://github.com/corral-dev/corral-apple) and [self-hosted relay](https://github.com/corral-dev/corral-relay).

The [organization profile](profile/README.md) links the three components. Bug and feature forms in [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) are shared by repositories without their own templates.

Documentation and templates: [MIT](LICENSE). Corral's name and artwork follow the [brand policy](https://github.com/corral-dev/corral-apple/blob/main/BRAND_POLICY.md). Product licenses are stated in each repository.
